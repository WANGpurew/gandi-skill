## 它是什么

Gandi 3.0 是MIT Scratch 血统的**积木编程互动作品平台**：一个功能完备的编辑器 + 本机 CLI + 运行时引擎 + 多人协作层。作品以 `.sb3` 保存，兼容 Scratch 2.0/3.0 并加入大量 Gandi 专有增强。这套文档有 99 篇、15 组，每篇讲一个功能"是什么/在哪/怎么用"，并如实标注未完成功能。

- **一句话**：在 Gandi 3.0 里从想法到发布作品的全流程功能参考。
- **主能力域**：CLI/AI 自动化、积木编程、作品文件与版本、多场景、素材创作、运行调试、引擎（物理/光照/粒子/地图）、扩展插件与协作。
- **只作背景不作能力**：开发者 API 手册（签名/注册点/编译管线）、协作运维（部署/环境变量/测试）、协作原理源码细节（消息编号/数据库表/握手时序）。这些在答疑时按需引用，不独立成可调用能力。

## 核心术语速览（完整 43 条见 glossary.md）

- **面板/组/分栏/浮窗**：四种界面容器；布局=排布方案，可存≤10套、导出 `.gandi-layout.json` 迁移。
- **通用设置 vs 作品设置**：前者跟人（登录上云），后者写进 sb3（舞台/帧率/克隆上限/编译）。
- **扩展 vs 插件**：扩展给作品加积木、随作品保存；插件改编辑器、装本机不写作品。
- **pull/push / base-rev / E_CONFLICT**：CLI 把作品当文件夹改；逐文件写带 base-rev 防冲突，冲突须重读。
- **积木页 / 模块 / 全局积木**：脚本分页；模块=只放代码的角色，可定义全作品同步的全局积木。
- **作用域三档**：全局(所有场景)/仅本场景(默认)/仅本角色；改作用域不可撤销。
- **编辑态 vs 运行态**：协作只同步显式编辑，运行时坐标/克隆/变量值不同步。
- **帧间隔 vs 补帧**：前者让速度独立于帧率（上限0.1秒），后者补中间位置让画面顺。
- **编译模式**：默认开、数量级提速；设断点或排查需临时关闭。
- **装配/覆盖**：光照/粒子/物理共用的物体配置，挂造型层级逐层覆盖，积木只改本次运行。
- **撤销只撤自己 / 软锁 / 换代**：协作心智模型，决定重连还是重新加载。

## 重要限制与"未完成"功能（来自文档自述）

- **版本历史/回收站存本机**：清浏览器数据即丢，不能代替保存；协作关闭=云端永久移除，先下载本地副本。
- **多场景兼容**：多场景作品拿到原版 Scratch 保存会静默丢其它场景；旧版编辑器保存会丢其它场景。
- **暂不可用/实验性**：云变量（开发中，数据管理盖遮罩）、作品服务四面板（无宿主点不动）、代码模式（实验默认关，草稿只存本机）、替换正则与成串积木替换（尚不支持）。
- **专有积木不通用**：Gandi 专有积木（`===`/三元/8类等）导出原版 Scratch 打不开；“添加到作品”（扩展当扩展装）不可用。
- **引擎前置**：光照/地图/粒子需 WebGL2；环境光 100% 看不见灯（降到约35%）；地图填错不报错；各引擎有数量上限。
- **CLI 只连本机**：不支持远程/云端；缺扩展页只读（E_DEGRADED_WRITE）。

## 批判性提示（判断边界）

文档默认读者懂积木编程基础，术语解释偏简；大量数值上限会随版本变化，使用前以当前文档为准；"功能百科"式组织不直接回答"多步任务该按什么顺序做"，本 skill 的价值正是把多篇功能串成可复用流程。
