## I — 方法论骨架 (Interpretation)

把"界面怎么摆"和"设置存哪里"两个入门问题，落到归属判断上：
① **四容器**——面板（功能区）、组（共享标签条的一叠面板）、分栏（按比例切格）、浮窗（浮于顶层）；工作区/造型/声音/地图每角色一个，舞台/积木栏全局唯一，积木栏随最后点过的工作区；
② **布局存取迁移**——摆好的面板存成一套布局（≤10 套），可另存、导出 .gandi-layout.json + 剪贴板、导入；Ctrl+←/→ 在自存布局间循环（预设不参与），触屏横滑；布局锁 Ctrl+Alt+L 收起拖拽缝与标题栏让位内容，但分隔条/切页/面板开关照常；
③ **顶栏三区**——左=文件菜单+作品名+场景胶囊+积木总数，中=面板开关 8 颗+全部功能抽屉，右=CLI 标记/布局/主题/搜索/设置；窄窗逐级收起；
④ **标签/浮窗操作**——悬停标签出"浮出/关闭"，双击最大化，拖标签在他页停约 0.5s 自动切页（Esc 取消），浮窗拖到停靠区边缘 14px 内铺满/半屏；
⑤ **设置二分（核心口径）**——判断"这项设置换作品后要不要变 / 会不会影响同一份代码的运行结果"：不变且属界面偏好进"通用"（跟人，登录上云），会变进"作品"（写进 sb3：舞台 4:3=480×360、16:9=640×360，帧率 30/60/120/不限，克隆上限默认 300，编译默认开）；改动即时生效无"确定"按钮；
⑥ **触屏映射**——长按 0.5s=右键（输入框与积木区除外）、双指捏合=缩放。
核心洞察：布局/偏好跟人走（靠导出导入迁移），影响运行结果的参数跟作品走（写进文件保证一致性）。

## A1 — 书中的应用 (Past Application)

### 案例一：布局跨设备迁移（procedure，slug: dock-layout / f01）
- **问题**：在自己电脑摆好的面板布局，换一台电脑想原样用回来。
- **方法执行**：拖面板到停靠区/分栏/浮窗摆好 → 顶栏"布局：×××"保存到当前套或另存为新布局（≤10）→ 导出为 .gandi-layout.json（同时复制到剪贴板）→ 换机后"从文件导入/从剪贴板导入" → Ctrl+←/→ 或触屏横滑在自存布局间切换。
- **结论**：文档所述效果——布局（含浮窗位置形态、关闭面板位置、积木栏状态）可存可换可迁移；但布局存在本机浏览器，换机必须靠导出/导入，积木栏状态只有从"布局"菜单切才跟着换。

### 案例二：判断一项设置归通用还是作品（decision-framework，slug: settings / f03、p01）
- **问题**：面对"主题语言"和"帧率"两项设置，该去哪里改、会不会影响别人打开同一作品的结果。
- **方法执行**：问"这项设置换作品后要不要变、会不会影响同一份代码的运行结果"→ 语言/主题/积木栏/快捷键/插件换作品不变，进"通用"（登录 CCW 后上云跨设备一致）→ 舞台大小/帧率/克隆上限/编译加速要变且影响运行结果，进"作品"（写进作品文件）→ 改完即生效，无确定按钮。
- **结论**：文档所述效果——设置二分保证"同一份代码在两人手里跑出同样结果"；作品设置写进文件，主题背景图/音效只存本机。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想摆好面板/分栏/浮窗并保存，或在多台电脑之间迁移界面配置。
2. 某个设置不知道该去"通用"还是"作品"里改，担心改了不生效或影响别人。
3. 想设置舞台比例、帧率、克隆上限、编译加速，或排查"不限帧率下动画不插值"。
4. 在平板/触屏上用编辑器，想知道长按、捏合对应什么鼠标操作；或想改快捷键。

### 语言信号
- "布局 / 面板 / 分栏 / 浮窗 / 布局锁 / 保存布局 / 换电脑界面配置"
- "设置 / 通用设置 / 作品设置 / 舞台 16:9 / 帧率 / 克隆上限 / 编译模式"
- "平板 / 触屏 / 长按右键 / 捏合缩放 / 快捷键改键"
- "layout / panel / dock / floating window / settings / shortcut / tablet"

### 与相邻 skill 的区分
- **本卡是 router 能力，经来源路由入口 `gandi-guide` 访问**：界面布局、设置归属、快捷键、主题、触屏等未独立成 Skill 的主题走本卡；具体积木创作任务由各独立 Skill 承接。
- 与 `blocks-authoring`（also_read）：本卡管编辑器界面布局与设置归属；blocks 管积木脚本组织。积木栏"定制/排序/隐藏"属 blocks，"布局存取/迁移"属本卡。
- 与 `run-debug`（also_read）：本卡管作品帧率/编译设置"在哪改、存哪里"；run-debug 管这些参数引发的运行问题（卡顿、断点与编译模式互斥）。"不限帧率动画插值失效"本卡讲设置现象，run-debug 讲排查。

## E — 可执行步骤 (Execution)

**输入契约**：一个要调整界面或设置的 Gandi 编辑器环境 + 明确意图（摆布局/迁移/改某设置/平板操作）；无需先有完整作品。
1. **摆面板与容器**：用面板/组/分栏/浮窗四容器把工作区摆好；积木栏随最后点过的工作区。完成标准：界面按习惯摆好。
2. **保存与迁移布局**：顶栏"布局：×××"保存/另存（≤10 套）→ 需迁移就导出 .gandi-layout.json（含剪贴板）→ 换机导入 → Ctrl+←/→ 切换自存布局。完成标准：换机后布局还原；判停：布局存本机，换机不导出导入就带不过去；积木栏状态只有菜单切才变。
3. **锁布局与浮窗操作**：Ctrl+Alt+L 锁布局（收拖拽缝，切页/分隔条/面板开关照常）→ 标签悬停浮出/双击最大化/拖动 0.5s 切页 → 浮窗拖到边缘 14px 内铺满半屏。完成标准：锁后误拖不发生、需要时点解锁。
4. **判设置归属**：逐项问"换作品要不要变、会不会影响同一份代码运行结果"→ 界面偏好进通用（登录上云）、运行参数进作品（写 sb3）→ 改完即生效。完成标准：每项设置归位、同一作品在两人手里结果一致；判停：主题背景图/音效只本机。
5. **设作品运行参数**：舞台 16:9=640×360、4:3=480×360 → 帧率 30/60/120/不限（新作品 60、导入作品 30）→ 克隆上限默认 300 → 编译默认开。完成标准：参数写进作品文件；判停：不限帧率下动画插值失效、排查报错要临时关编译。
6. **平板/快捷键适配**：触屏长按 0.5s=右键（输入框与积木区除外）、捏合=缩放 → 需改键到设置→快捷键录制（Esc 放弃、退格清空、只存改过的键）。完成标准：触屏与改键按预期工作；判停：Ctrl+Shift+F 可能被中文输入法吃掉，需改键。
**输出契约**：一套摆好并保存（必要时已导出）的布局 + 一份"设置归属判定表"（哪些进通用、哪些进作品及取值）+ 触屏/快捷键适配说明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 具体积木与创作任务（分页/自制积木/作用域/脚本）——用 `blocks-authoring` 等独立 Skill。
- 运行卡顿、断点单步、变量异常——用 `run-debug`；本卡只讲帧率/编译"在哪改"。
- 作品文件打开保存与备份——用 `project-files`。

### 作者在文档中警告的失败模式
- 布局存本机：布局存在本机浏览器，换机必须靠导出/导入；主题背景图/音效只本机，登录上云也不带。
- 不限帧率动画插值失效：帧率设"不限"跟屏幕刷新率跑、每帧都是真的，动画插值不起作用——为"画面顺"设不限等于白设。
- 编译模式排查要关：编译过的脚本报错方式不同、少数积木行为有细微出入，排查报错/逐步观察须临时关编译模式。
- 积木栏状态只在菜单切才变：快捷键/触屏横滑切布局不带积木栏状态；协作跟随中布局不可改。

### 文档的盲点 / 局限
- 布局 ≤10 套；布局锁只收拖拽缝/标题栏，分隔条/切页/面板开关照常；Esc 在多数浮层管用，唯独设置对话框要用 × 或点外面。
- 作品页舞台尺寸是"格数"非屏幕像素：4:3=480×360、16:9=640×360，非标准尺寸不高亮不静默改；帧率可填 1–250、克隆上限可设"不限"（真无上限，有内存耗尽风险）。
- CLI 标记/云背包/作品服务依赖宿主，网页版无；多语言只换界面/积木/扩展文字，作品里的名字不换、缺翻译退回中文。

### 容易混淆的邻近方法论
- "通用跟人"与"作品跟作品"：前者换作品不变、可上云，后者写进文件随作品走——判断口径是"会不会影响同一份代码的运行结果"。
- "舞台尺寸模式"（固定/跟随面板/横向扩展/纵向扩展）改的是"舞台有多少格"，不是一格多大；放大面板不是把 480 格拉大。
- "布局锁"与"协作跟随锁"：前者自己锁布局防误拖，后者跟随别人时布局被临时锁住且按不动锁按钮。
