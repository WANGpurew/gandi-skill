## I — 方法论骨架 (Interpretation)

把"画造型、做动画、清录音、写曲子"四类素材创作，各落成一条固定流：
① **造型绘制**——矢量位图混排、编辑即所见、停手 0.4 秒自动写回（无保存按钮）；工具快捷键：选择 V/节点 A/钢笔 P/画笔 B/橡皮 E/图形 ROYKL/位图 M/文字 T/取色 I/油漆桶 G；钢笔仿 Figma（单击尖角、拖平滑点、Alt 分手柄、Shift 锁 45°）；填 4 种渐变+6 效果+16 混合模式；共用图首改问"仅修改此角色/全部更新"；
② **逐帧动画**——造型条一帧=一造型；播放 fps 1-60（默认 8）、洋葱皮对照、补间把一张和右边一张间插 1-30 张（默认 3）归入"起始帧名⟩补"组；GIF/视频可当造型（克隆体共用进度、滤镜不作用于动图），导出 WebM；
③ **音频清洗**——波形选区（Alt 吸附过零点防爆音、Shift+粘贴=混音）→ 切频谱、框纯噪声段"学习噪声"再"降噪"（留一点底噪更自然）、去嗡嗡（中国 50Hz）→ 加效果/音量包络 → 存回 44100Hz 立体声；声音三类型（采样/乐曲/音色）无新建入口；
④ **写曲流**——编曲台（一轨一乐器、摆片段、循环区）→ 钢琴卷帘（画音符、量化、演奏曲线）→ 混音台（音量/声像/效果链/总线/自动化）→ 乐器与音色 → 渲染音频；波形/频谱显示的是曲子渲染出的音频，编曲台才是改音符的界面。
核心洞察：素材类操作强依赖可视化编辑器手操，AI/agent 难以代替执行质量——本卡给的是流程与边界，动手在编辑器里完成；且共用素材首改、跨平台兼容是两处关键决策点。

## A1 — 书中的应用 (Past Application)

### 案例一：逐帧动画制作——复制微调再补间导出（procedure，slug: paint2-frames / f28）
- **问题**：想做一个走路动画，不想一帧一帧全画出来。
- **方法执行**：造型条加帧（一帧=一造型）→ 复制关键帧并微调 → 开洋葱皮对照 → 选中帧按"补间"（1-30 张、默认 3），它在本帧与右边那帧间插过渡帧并归入"起始帧名⟩补"组 → 设缓动/淡入淡出/相似度门槛/图层配对 → 导出 WebM。
- **结论**：文档所述效果——只画首尾两张中间自动算；补出来的帧归"补间组"可整组删除，补间设置只存本地不进作品；GIF 在别的编辑器只显首帧、mp4/webm 造型可能让整个作品打不开。

### 案例二：音频清洗——先学噪声再降噪（worked_example，slug: sound2 / f29、p13）
- **问题**：一段录音有底噪和嗡嗡声，想清理干净又不失真。
- **方法执行**：波形选区（Alt 吸附过零点防爆音）→ 切频谱、"更多：降噪、去嗡嗡"→ 框一段只有噪声无人声的区间（通常开头静音）"学习噪声"再"降噪"（力度/保留度两滑杆）→ 选市电频率去嗡嗡（中国 50Hz）→ 加效果/音量包络 → "存回声音"。
- **结论**：文档所述效果——存回规格固定 44100Hz 立体声、与浏览器试听采样率一致；留一点底噪比完全去除更自然（全去会"水下咕噜声"），去嗡嗡选错只是没效果；共用声音首改同样问"仅修改此角色/全部更新"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想画造型、用钢笔画路径、加渐变效果或把文字转轮廓。
2. 想做逐帧动画、加补间过渡帧、开洋葱皮对照或导出 WebM 视频；想用 GIF/视频当造型。
3. 有一段录音想降噪、去嗡嗡、防爆音后存回作品。
4. 想从零写一首曲子（编曲→填音符→混音→选乐器），或改已有乐曲的音符。

### 语言信号
- "画造型 / 矢量 / 钢笔 / 渐变 / 文字转轮廓 / 字体"
- "逐帧动画 / 补间 / 洋葱皮 / 帧率 / 导出 WebM / GIF 造型"
- "录音降噪 / 学习噪声 / 去嗡嗡 / 44100Hz / 波形选区"
- "写曲 / 编曲台 / 钢琴卷帘 / 混音台 / 乐器音色 / 量化"
- "costume / paint / tween / onion skin / denoise / arrange / mixer / MIDI"

### 与相邻 skill 的区分
- **本卡是 router 能力，经来源路由入口 `gandi-guide` 访问**：造型/动画/声音等素材创作与快捷键走本卡；素材在场景间的复用决策由独立 Skill 承接。
- 与 `scenes-assets`（also_read）：本卡管"素材怎么画、怎么改、怎么导出"；scenes 管"素材在场景/角色间是共用还是独立副本"。共用图首改问"仅修改此角色/全部更新"时，分出的副本归入 scenes 的复用规则。
- 与 `engine-tools`（also_read）：本卡产出造型/声音素材；engine 把碰撞体/灯/发射器挂到造型文件夹做引擎配置——"按轮廓生成多边形"用的是本卡画出的不透明像素。

## E — 可执行步骤 (Execution)

**输入契约**：一个要画造型/做动画/清声音/写曲的 Gandi 作品 + 素材意图；明确素材是否共用（决定是否分副本）。
1. **画造型**：选工具（V/A/P/B/E/ROYKL/M/T/I/G）→ 钢笔仿 Figma 画路径 → 填渐变/效果/混合模式 → 文字转轮廓（如需）→ 停手 0.4 秒自动写回。完成标准：造型按预期呈现、舞台同步更新；判停：无保存按钮、文字转轮廓不可逆、共用图首改要选仅此角色/全部更新。
2. **做动画**：造型条加帧（一帧=一造型）→ 复制关键帧微调 → 开洋葱皮 → 补间 1-30 张 → 设缓动/淡入淡出 → 导出 WebM。完成标准：动画连贯、导出成功；判停：补间帧归"补"组可整组删、补间设置只存本地；GIF/视频当造型的兼容限制见 B。
3. **清声音**：波形选区（Alt 吸附过零点）→ 切频谱 → 框纯噪声段"学习噪声"再"降噪"→ 去嗡嗡（中国 50Hz）→ 效果/包络 → 存回 44100Hz 立体声。完成标准：底噪去除且不过度、无爆音；判停：全去会"水下咕噜声"、去嗡嗡选错只是没效果。
4. **写曲（按需）**：新建乐曲 → 编曲台加轨道摆片段/循环区 → 钢琴卷帘画音符并量化 → 混音台设效果链/总线/自动化 → 选乐器音色 → 渲染音频。完成标准：曲子渲染出音频；判停：波形/频谱显示的是渲染结果，改音符要回编曲台/卷帘；渲染需等待。
5. **核对兼容与字体**：跨编辑器使用的造型避免 GIF/视频（只显首帧或打不开）；需要保留字形用"随作品"字体，别用"仅本机"。完成标准：发给别人不换字、不乱版；判停：角度/菱形渐变烘成 512 图放大糊。
**输出契约**：画好的造型/逐帧动画（含补间组与导出的 WebM）+ 清洗后 44100Hz 立体声声音 +（如需）写好的乐曲 + 字体/兼容处理说明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 素材在场景/角色间的共用与独立副本决策——用 `scenes-assets`。
- 给造型挂碰撞体/灯/发射器做引擎配置——用 `engine-tools`。
- 素材文件的打开保存与备份——用 `project-files`。

### 作者在文档中警告的失败模式
- 文字转轮廓不可逆；"仅本机"字体发给别人会换字——发给别人前用"随作品"（嵌字形）或转轮廓。
- 角度/菱形渐变烘成 512 图、放大就糊，文件几十~几百 KB——需要放大清晰时避免此类渐变。
- GIF/视频造型兼容坑：GIF 在别的编辑器只显首帧、嵌在矢量里的动图变静态图，mp4/webm 造型可能让整个作品打不开——跨编辑器用前先确认。
- 无保存按钮 + 共用图首改询问：造型停手 0.4 秒自动写回、没有保存按钮；首次改共用图要选"仅修改此角色"或"全部更新"，别误改全部。

### 文档的盲点 / 局限
- 播放帧率 1-60（默认 8）、补间 1-30 张（默认 3）；克隆体共用 GIF/视频进度、滤镜不作用于动图。
- 存回声音固定 44100Hz 立体声；声音三类型（采样/乐曲/音色）无新建入口；去嗡嗡针对 50Hz（中国市电）。
- 写曲主按钮是"渲染音频"（尚未完成且需等待）；曲子本身自动保存，波形/频谱只是渲染结果不是编辑界面。
- emoji 转轮廓只能单色剪影；组件库跨作品图形库属进阶，普通造型编辑不涉及。

### 容易混淆的邻近方法论
- "随作品"字体（嵌字形、发给别人不换字）vs "仅本机"字体（本机有、别人换字）——分享作品前要确认。
- "补间帧组"（"起始帧名⟩补"，可整组删除、设置只存本地）vs 普通造型文件夹——补出来的帧不进普通文件夹。
- "从库中选择"（下载新份）vs "从资源库"（加引用）——素材复用两条路径，与 scenes 卡共用概念。
- 声音"降噪"（去宽频底噪，先学噪声）vs "去嗡嗡"（去特定市电频率 50Hz）——两个不同操作。
