## I — 方法论骨架 (Interpretation)

把"大脚本找不到、改不动"的问题，拆成整理（代码框/多工作区）与查找替换（Ctrl+F/Ctrl+H）与快速生成（中键）：
① **代码框**——工作区空白右键"创建代码框"（或 Ctrl+A 拖矩形，<20×20 不留），按"碰到"判定归属（角压 1/10 也算）；可命名、整体拖、改色、上锁、导出 SVG；折叠是真卸下积木减负；Delete 删连积木一步撤销；只属画它那一页；
② **多工作区**——同页开多个工作区，一个"跟随"选中角色、其余"钉住"固定角色/页；积木栏全局唯一、随最后点过的工作区；跨区拖积木=移动（同页双面板实时同步，拖回栏=删除）；小地图默认关；
③ **全局搜索 Ctrl+F**——搜整作品（积木/角色/页/素材/变量/注释），积木文字+值黄色高亮、同页相同折成 ×N；拼音首字母（原文>整拼音>首字母>模糊）、分类过滤+只看当前角色、一屏≤80 条、回车跳（优先已开工作区、亮 2.6s）；
④ **查找替换 Ctrl+H**——两行输入边打边出（停 0.2s 查），是可搬的窗非弹窗；"找什么"打字找值（数字/文字/下拉/注释，Aa 区分大小写、全字匹配）或放真积木一块换一块；槽状态 就这个值/任意/任意①（记住值，"换成"可引用①）；
⑤ **范围与撤销**——范围四档：本代码页/当前角色（默认）/当前场景/整个作品（跨未打开角色）；形状不符拒换、会丢内容逐条列；"换成"留空多出"删除 N 处"（帽子不参与）；一次替换一步撤销；
⑥ **快捷添加**——空白中键或栏放大镜弹框，中文一句话拼多块（原文/拼音/首字母、运算词翻符号），断句词"然后/接着/之后/并且/同时/最后"，↑↓ 选、Alt+数字直选、像 DSL 切多行、剪贴板是 DSL 时 Ctrl+V 直接贴成积木。
核心洞察：先整理分组、再定位、再成批替换；替换默认只作用于当前角色，范围选大撤销代价不对称。

## A1 — 书中的应用 (Past Application)

### 案例一：查找替换"任意①"跨积木搬运参数值（worked_example，slug: find-replace / c09）
- **问题**：想把所有的"移动 (10) 步"换成"在 (1) 秒内滑行到 x: (原值) y: (0)"，不同积木里的数各不相同，不能写死一个数。
- **方法执行**：Ctrl+H →"找什么"放真积木"移动 (任意①) 步"，槽点一下切到"任意①"（填什么都算并记住）→"换成"放"在 (1) 秒内滑行到 x: (①) y: (0)"，x 槽选"引用①" → 设范围（默认当前角色）→ 去掉不想改的勾 → 点"替换 N 处"。
- **结论**：文档所述效果——移动 10 步和移动 25 步各自把自己的数搬进新积木的 x；整次替换按一次 Ctrl+Z 全部回去；形状不符拒换、会被丢掉的内容逐条列出。

### 案例二：代码框圈起并折叠一组脚本（procedure，slug: frames / f13）
- **问题**：工作区脚本散乱，想给一组脚本起名、整体搬动、不看时折起来减负。
- **方法执行**：空白处右键"创建代码框"或 Ctrl+A 拖矩形 → 按"碰到"判定哪些脚本归属（角压 1/10 也算）→ 双击标题改名 → 折叠卸下积木减负 → 选中可拖/改色/上锁/导出 SVG。
- **结论**：文档所述效果——代码框是圈在脚本外的矩形，连框带积木一起搬；折叠是真卸下积木、Delete 删连积木一步撤销，但没有"只删框留积木"入口（靠 Ctrl+Z）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 作品很大，想快速找到某块积木、某个变量或某段注释在哪。
2. 想把"所有的 10 换成 15"或"所有的'你好'换成'Hi'"成批改掉，并担心改错想整体撤回。
3. 工作区堆了一大片脚本，想分组折叠、多开几个工作区对照两个角色。
4. 想用中文一句话快速生成一串积木，或把剪贴板里的 DSL 贴成积木。

### 语言信号
- "查找 / 搜索 / 某个积木在哪 / Ctrl+F / 拼音首字母"
- "批量替换 / 把所有的 X 换成 Y / Ctrl+H / 范围 / 一步撤销"
- "代码框 / 折叠 / 整理脚本 / 多工作区 / 跟随钉住 / 小地图"
- "一句话生成积木 / 中键 / 快捷添加 / 剪贴板贴 DSL"
- "find / replace / refactor / quick add / frames / search"

### 与相邻 skill 的区分
- **本卡是 router 能力，经来源路由入口 `gandi-guide` 访问**：整理查找、折叠、快捷添加等编辑器操作技巧走本卡；新建积木结构由独立 Skill 承接。
- 与 `blocks-authoring`（also_read）：本卡管"查找/替换/折叠已有积木"；blocks 管"设计新的自制/全局积木、变量作用域"。要批量替换已有值用本卡，要造新积木结构用 blocks。
- 与 `cli-authoring`（also_read）：本卡在编辑器内交互操作；CLI 卡用 `gandi grep/blocks` 在文件里搜、按 DSL 改。两者都是"查找"，一个在界面一个在命令行。

## E — 可执行步骤 (Execution)

**输入契约**：一个要整理或查找的 Gandi 作品 + 明确意图（定位/替换/折叠/一句话生成）；替换前建议先存一版以便回退。
1. **整理分组（按需）**：空白右键创建代码框 → 按"碰到"归组 → 命名/改色/上锁 → 折叠减负 → 可导出 SVG。完成标准：脚本分组清晰、折叠后减负；判停：无"只删框留积木"入口，靠 Ctrl+Z；框不嵌套、只属一页。
2. **多工作区对照（按需）**：角色右键"在新面板打开"或 Ctrl+Enter 钉浮窗 → 跟随区随选中角色、钉住区固定 → 积木栏随最后点过的工作区 → 跨区拖积木=移动。完成标准：能同时对照两个角色并直接搬积木；判停：拖回栏=删除，同页双面板实时同步。
3. **定位 Ctrl+F**：Ctrl+F → 输入（原文/拼音/首字母）→ 分类过滤+只看当前角色 → ↑↓ 选 → 回车跳（亮 2.6s）。完成标准：跳到目标并高亮；判停：同页相同折成 ×N 需点开、一屏≤80 条、Ctrl+F 再按一次全选输入框。
4. **替换 Ctrl+H**：Ctrl+H →"找什么"打字找值或放真积木 → 槽设 就这个值/任意/任意① → 设范围（本代码页/当前角色默认/当前场景/整个作品）→ 设"换成"（可引用①，留空=删除 N 处）→ 勾结果 → 替换。完成标准：替换到位、整次一步 Ctrl+Z 可全撤；判停：形状不符拒换、会丢内容逐条列、结果≤400 条。
5. **一句话生成（按需）**：空白中键或栏放大镜 → 中文一句话（断句词 然后/接着/并且/同时/最后）→ ↑↓ 选或 Alt+数字直选 → 回车放下/拖走；剪贴板是 DSL 时 Ctrl+V 贴成积木。完成标准：整串积木生成；判停：按在积木/栏/气泡/下拉上不弹出、>200KB 先问、撤销时新建变量不跟着撤。
**输出契约**：整理好的脚本分组（代码框/多工作区）+ 定位记录 + 一次可一步撤销的批量替换结果（含范围与结果条数）+（如需）一句话生成的积木串。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 设计新的自制积木、全局积木或选变量作用域——用 `blocks-authoring`。
- 在命令行/文件里批量搜改作品——用 `cli-authoring` 的 grep/blocks/DSL。
- 排查运行期的卡顿、变量异常——用 `run-debug`。

### 作者在文档中警告的失败模式
- 替换正则还不支持、成串积木/整段写法替换目前不支持："找什么"只认字面的字，按单值或单块匹配——想用 `.*` 或整段替换都做不到。
- 范围选大撤销代价不对称：范围选小了再点一次就行，选大了要靠撤销挽回；跨未打开角色、无工作区打开时替换撤不回。结果是 400 条上限。
- 代码框无"只删框留积木"入口：靠 Ctrl+Z；折叠框不收新积木、框不嵌套、一个框只属画它那一页。
- 中文输入法下 Ctrl+Shift+F 可能被吃：文件中搜索/快捷添加相关快捷键需留意，必要时改键。

### 文档的盲点 / 局限
- 查找替换结果 ≤400 条，全局搜索一屏 ≤80 条；一次替换一步撤销；改名走专门入口不是替换。
- 槽状态"任意①"记住值可跨积木搬运，但新建的变量在撤销时不跟着撤；快捷添加 >200KB 先问。
- 全局搜索匹配跑在作品数据上不依赖界面；小地图默认关、只画积木不画注释/影子块。
- Gandi 2.0 导出的 SVG 无积木数据、拖不回；自制积木定义不能存成片段。

### 容易混淆的邻近方法论
- Ctrl+F（全局搜索定位）vs Ctrl+H（查找替换并改）：前者只找不跳转修改，后者成批改且一步撤销。
- "任意"（每次匹配任意值但不跨积木记）vs "任意①"（记住值且"换成"可引用）——做参数搬运要用任意①。
- 代码框"折叠"（真卸下积木减负）vs 积木栏分组标题"折叠"（只收起显示）——作用于不同对象。
- "清理冗余积木"（删未用项，属维护）vs "整理积木"（只摆齐不改内容）——两者常一起用但不同。
