# 决策规则速查 — Gandi 3.0 功能文档

| 能力 | 一句话规则 |
|---|---|
| 用 CLI/AI 读写与验证作品（含 DSL） | gandi up 授权→pull→按DSL改文件→check带base-rev→push→run/view/state/assert 验证→doctor/history 排障找回。 |
| 运行调试与排错（卡顿/断点/静态检查） | F3看状态→录制找卡顿→概览/帧/积木页定位→断点单步→数据面板改值→诊断/静态检查；设断点先关编译。 |
| 积木编程与脚本组织 | 用积木页分脚本、自制/全局积木消除重复、变量作用域建时就选对(改作用域不可撤销)。 |
| 作品文件、版本回滚与数据保全 | 打开保存.sb3；改坏了看版本历史diff→预览→还原或只取回角色；版本与回收站在本机，须先存作品再动协作。 |
| 多场景架构与素材复用 | 角色设跨场景常驻→作品分场景→带参切换与广播通信；共用素材改动前先决定仅此角色还是全部更新。 |
| 引擎搭建：物理/光照/粒子/瓦片地图 | 装配编辑器给造型挂物理/光照/粒子配置并逐层覆盖；积木只改本次运行；用前确认WebGL2与各类上限。 |
| 扩展插件与多人协作 | 扩展给作品加积木、插件改编辑器；协作开→邀请按权限组→进入；只同步编辑态不同步运行态，撤销只撤自己，关协作前先备份。 |
| 界面布局、工作区与设置归属 | 面板可停靠/分栏/浮窗，布局存导出再导入迁移；设置分通用(跟人)与作品(写进文件)。 |
| 整理、查找与批量替换积木 | 代码框圈起并折叠脚本；Ctrl+F分类过滤跳转；Ctrl+H先列结果后替换，范围默认当前角色，一步撤销。 |
| 造型、动画与声音素材创作 | 造型矢量位图混编、逐帧动画复制微调补间导WebM、声音降噪后44100Hz存回、写曲走编曲→卷帘→混音→乐器。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
